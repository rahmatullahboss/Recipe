# Ozzyl Recipes

A Cloudflare-native recipe publishing platform inspired by the information architecture of large recipe communities, while using an original brand, interface, and content.

The application is designed to run entirely on Cloudflare Workers with Astro SSR, Workers Static Assets, D1, R2, KV sessions, Cloudflare Images, Turnstile, and optional Queues/Vectorize extensions.

Development work is tracked through feature branches and pull requests.
